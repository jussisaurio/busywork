## Grading
List every problem you find, in your question's scope. There is no quota: none is a good answer when you find none,
and so are twelve. Grade each one:
- `blocker`: a player would misunderstand a route or a cause, a person or a thing acts as it never would in a real
  office, or the name or the card gives away the way out.
- `should`: it hurts, but it misleads nobody.
- `nit`: polish.

The verdict counts blockers only: `works` when you list none, `fixable` when you list any, and `broken` only as your
question defines it. Write the verdict line to match.

If earlier.md is in your folder, it holds the problems an earlier reader found in an earlier version of this level.
Before your own list, mark each of them, by its number (E1, E2, ...):
```
## Earlier problems
- E1: fixed|still there|no longer applies — <one line why>
```
Do not list an earlier problem again under Problems: one still there is carried for you, as a blocker. Count it in
your verdict.

End your report with your own list (new problems only), most serious first:
```
## Problems
- blocker: <the problem> — <one concrete fix>
- should: <the problem> — <one concrete fix>
- nit: <the problem> — <one concrete fix>
```
or `- none`.
